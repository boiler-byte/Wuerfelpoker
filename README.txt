Покер на костях – Russisches Würfelpoker

Spiel starten:
1. ZIP-Datei entpacken.
2. index.html im Browser öffnen.
3. Schwierigkeit auswählen und auf „Spiel starten“ klicken.

Enthaltene Dateien:
- index.html: Startbildschirm und Spieloberfläche
- style.css: Gestaltung und Animationen
- game.js: Spielablauf, Würfellogik und Computergegner
- sound.js: Soundeffekte (Web Audio, ohne externe Dateien)
- regeln.html: separate Spielregeln für den Dialog

Die Würfel rollen als animierte 3D-Würfel über den Tisch und bleiben mit ihrem Ergebnis liegen.
Soundeffekte fuer Wuerfeln, Behalten, Bedienung und Rundenergebnisse.
Ueber "Ton an / Ton aus" lassen sie sich stummschalten. Die Einstellung
wird nach Moeglichkeit im Browser gespeichert.

Das Spiel laeuft ohne Internet, Installation oder Server.

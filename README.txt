Покер на костях – Russisches Würfelpoker

Spiel starten:
1. ZIP-Datei entpacken.
2. index.html im Browser öffnen.
3. Schwierigkeit auswählen und auf „Spiel starten“ klicken.

Enthaltene Dateien:
- index.html: Startbildschirm und Spieloberfläche
- style.css: Gestaltung und Animationen
- game.js: Spielablauf, Würfellogik und Computergegner
- regeln.html: separate Spielregeln für den Dialog

Das Spiel läuft ohne Internet, Installation oder Server.
